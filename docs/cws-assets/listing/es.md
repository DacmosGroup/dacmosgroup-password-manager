## Description

🔒 Dacmos Password Manager — Seguridad de nivel empresarial para todos

Gestiona tus contraseñas con el mismo estándar de cifrado que usan los bancos y gobiernos, sin depender de servidores externos.

🌐 MODELO ZERO-KNOWLEDGE
Tu contraseña maestra nunca abandona tu dispositivo. Ni DacmosGroup ni nadie más puede acceder a tus datos. Solo tú.

🔐 CIFRADO DE NIVEL BANCARIO
- AES-256-GCM (NIST FIPS 197)
- PBKDF2-SHA256 con 600,000 iteraciones (OWASP 2024)
- Web Crypto API nativa — sin librerías de terceros

🌎 NUEVO EN v0.5.0 — TU IDIOMA
Interfaz disponible en Español, English y Português (BR).
Se adapta automáticamente al idioma de tu Chrome — sin configurar nada.

Exportar en CSV genérico y CSV compatible con Bitwarden
Autocompletado en formularios de login, checkout y registro
URL matching robusto: subdominios, wildcards y dominio base
