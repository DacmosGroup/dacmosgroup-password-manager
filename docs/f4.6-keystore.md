## Backup obligatorio

> ⚠️ **CRÍTICO:** Si el keystore se pierde, es IMPOSIBLE publicar actualizaciones
> del APK bajo la misma identidad de app (`co.dacmosgroup.dpm`). Perder el keystore
> equivale a perder la identidad de la app en todos los stores y canales de
> distribución donde esté publicada.

**Instrucción al founder (Alejandro Seijas):**

1. Guardar una copia del archivo `dacmos-release.keystore` en:
   - Google Drive personal (cuenta dacmos@outlook.com)
   - Un segundo destino offline (USB cifrado, Bitwarden como adjunto, etc.)
2. Guardar también la contraseña del keystore/key en Dacmos Password Manager
   (o en Bitwarden como respaldo externo)
3. Verificar al menos una vez al año que el backup sigue accesible

**Contraseña del keystore:** almacenada en Dacmos Password Manager bajo la
entrada correspondiente a "DacmosGroup Android Keystore".

## Uso en bubblewrap

El archivo `twa-manifest.json` en la raíz del repo referencia el keystore:

```json
"signingKey": {
  "path": "C:/DacmosGroup/03_PasswordManager/dacmosgroup-password-manager/dacmos-release.keystore",
  "alias": "dacmos-dpm"
}
```

Al clonar el repo en otro equipo, actualizar `signingKey.path` con la ruta
absoluta correcta en el nuevo sistema antes de ejecutar `bubblewrap build`.

## Comandos de referencia

```bash
# Verificar fingerprints del keystore
keytool -list -v \
  -keystore dacmos-release.keystore \
  -alias dacmos-dpm \
  -storepass <contraseña>

# Build del APK (desde la raíz del repo)
bubblewrap build --skipPwaValidation

# Renombrar output con versión
# cp app-release-signed.apk dacmos-pm-v0.4.0.apk
```
